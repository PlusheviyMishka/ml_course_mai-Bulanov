# Wine Quality

Источник: [UCI Machine Learning Repository — Wine Quality](https://archive.ics.uci.edu/dataset/186/wine+quality).

Авторы: Paulo Cortez, António Cerdeira, Fernando Almeida, Telmo Matos, José Reis (2009).
DOI: [10.24432/C56S3T](https://doi.org/10.24432/C56S3T).
Лицензия, указанная UCI: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Скачаны 20 октября 2026 года из официального архива UCI.
CSV сохранены без изменений:

- `winequality-red.csv` — 1599 строк данных.
- `winequality-white.csv` — 4898 строк данных.

Разделитель — `;`. В каждом файле 11 признаков и целевой столбец `quality`.
При объединении в учебном примере добавляется `is_red`: 1 для красного, 0 для белого.
Готовых прогнозов и результатов лабораторной в этих файлах нет.
